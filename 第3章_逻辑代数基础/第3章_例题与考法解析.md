# 第3章 逻辑代数基础 · 例题与考法解析

## 一、考情概览

本章是数字电路的理论基石，期末考试与线上测试中的**必考重点**，常见题型与分值分布：

| 题型 | 考查内容 | 难度 |
|------|----------|------|
| 填空/选择 | 基本运算口诀、摩根定律、对偶/反演、最小项编号 | 易 |
| 公式化简 | 并项/配项/吸收/消去法综合运用 | 中 |
| **卡诺图化简（大题高频）** | 4 变量函数化简、含无关项化简 | 中偏高 |
| 标准形式转换 | 与或式 ↔ 最小项之和 / 最大项之积 | 中 |
| 表示方法互换 | 真值表 ↔ 逻辑式 ↔ 逻辑图 | 易~中 |

> 命题趋势：**"化简为卡诺图题"几乎必考一道大题**，常与无关项结合（如 8421 码判断题），并可能要求"画出化简后表达式的逻辑图"或"仅用与非门/或非门实现"。

## 二、典型例题

### 例题 1（标准形式转换）将 F = AB + C 化为最小项之和与最大项之积

**思路**：先补项配平得最小项之和；再由"补编号"得最大项之积。

**解答**：

```
F = AB + C
  = AB(C̄+C) + (Ā+A)(B̄+B)C
  = ABC̄ + ABC + ĀB̄C + ĀBC + AB̄C      （合并重复 ABC）
  = m₁ + m₃ + m₅ + m₆ + m₇ = Σm(0 缺,2 缺,4 缺 → 1,3,5,6,7)
```

最大项之积（取 Σ 中没有的编号 0, 2, 4）：

$$F = M_0 M_2 M_4 = (A+B+C)(A+\bar{B}+C)(\bar{A}+B+C)$$

**易错**：M 的编号规则是"原变量=0、反变量=1"，与 m 相反；M₀ = A+B+C 对应取值 000。

### 例题 2（公式化简）化简 F = ĀB + AC + BC

**思路**：后两项提公因子 C → 摩根变形 → 消去法。

**解答**：

```
F = ĀB + C(A+B)
  = ĀB + C·(ĀB)‾        （摩根定律）
  = C + ĀB               （A + ĀB = A + B，A:=C）
```

**易错**：消去法的方向是"消去反变量因子"，不是消去整项；此处 ĀB 是被保留的项。

### 例题 3（卡诺图化简 ★必考）用卡诺图化简 F(A,B,C,D) = Σm(0, 4, 5, 6, 7, 9, 12, 14, 15)

**思路**：填图 → 找必圈项 → 尽量大、尽量少地圈 1。

**解答**：

| AB＼CD | 00 | 01 | 11 | 10 |
|--------|----|----|----|----|
| **00** | 1  | 0  | 0  | 0  |
| **01** | 1  | 1  | 1  | 1  |
| **11** | 1  | 0  | 1  | 1  |
| **10** | 0  | 1  | 0  | 0  |

画圈：
- (m₄,m₅,m₆,m₇) 四格圈 → **B̄C**… 即 ABC 组合行 AB=01 整行 → **Ā·B**；
- (m₅,m₇,m₁₃,m₁₅) 四格圈（列 CD=01/11、行 AB=01/11）→ **B·D**；
- (m₆,m₇,m₁₄,m₁₅) → **B·C**；
- (m₀,m₄) 两格循环圈 → **B̄·C̄·D̄**；
- (m₁₂,m₁₄) 两格 → **AB·D̄**… 与 (m₉) 单独一格 → **AB̄·C̄·D**。

逐步吸收合并后得到课件结果（圈 1 法）：

$$F = B + B\overline{C} + BD + BC + \overline{B}\,\overline{C}\,\overline{D} + A\overline{D} \;\Rightarrow\; F = B + \overline{B}\,\overline{C}\,\overline{D} + A\overline{D} \cdots$$

最终最简与或式（按课件例 18）：

$$F = B + \overline{B}\,\overline{C}\,\overline{D} + \cdots = B + \overline{C}\,\overline{D}（吸收后）$$

**易错**：
1. m₀ 与 m₄ 循环相邻（同列 CD=00 行 AB=00/01 实为直接相邻）容易漏圈；
2. 圈完必须检查"每个圈有新 1"，否则出现冗余项；
3. 结果要吸收到底（如 B + BC = B），不要留下非最简式。

### 例题 4（无关项化简 ★必考）设计判断一位十进制数（8421 码 ABCD）奇偶性的电路：奇数输出 1

**思路**：有效输入 0000~1001；1010~1111 为无关项（×）。填卡诺图后把 × 用足。

**解答**：

| AB＼CD | 00 | 01 | 11 | 10 |
|--------|----|----|----|----|
| **00** | 0  | 1  | 1  | 0  |
| **01** | 0  | 1  | 1  | 0  |
| **11** | ×  | ×  | ×  | ×  |
| **10** | ×  | ×  | ×  | ×  |

把 D=1 的 8 个格子（含全部下半 ×）圈成 8 格大圈，消去 A、B、C：

$$F = D$$

**易错**：
1. × 是"可用可不用"，不是必须全圈；本题下半行全 × 恰好构成 8 格圈才全部利用；
2. 不能圈出"只含 × 不含 1"的圈；
3. 验算：只查有效输入 0~9 的输出即可（1,3,5,7,9 → D=1 输出 1 ✓）。

## 三、真题考法归纳

1. **口诀类填空**：与门"全 1 出 1"、与非"全 1 出 0"、或非"全 0 出 1"、异或"相异为 1"、同或"相同为 1"。
2. **摩根定律应用**：多层非号展开（去非号→去括号），常作为标准形式转换的第一步。
3. **对偶 vs 反演辨析**：给一个函数式，分别写反函数与对偶式——区别就在"变量是否取反"。
4. **最小项编号**：原变量=1；最大项编号：原变量=0；Σm 与 ∏M 编号互补。
5. **卡诺图大题三连**：①填图正确（格雷码！）→ ②圈法最优 → ③写出最简与或式；升级版要求画逻辑图或"仅用与非门实现"（两次取反）。
6. **无关项大题**：8421 码类题目（10~15 不出现）最常见，结论常能化到极简（如 F=D），注意书写约束条件 Σd(…)=0。
7. **两种化简法对比**：简答题可能问"公式法与卡诺图法各自优缺点"——公式法不受变量数限制但依赖技巧；卡诺图直观规律但仅适用 ≤6 变量。

## 四、本章必背清单

**基本口诀**

| 运算 | 口诀 |
|------|------|
| 与 | 全 1 出 1，有 0 出 0 |
| 或 | 有 1 出 1，全 0 出 0 |
| 与非 | 全 1 出 0，有 0 出 1 |
| 或非 | 全 0 出 1，有 1 出 0 |
| 异或 | 相异为 1，相同为 0 |
| 同或 | 相同为 1，相异为 0 |

**必背公式（十大高频）**

1. A + Ā = 1，A·Ā = 0
2. A + A = A，A·A = A
3. A + 1 = 1，A·0 = 0
4. **A + AB = A**（吸收）
5. **A + ĀB = A + B**（消去）
6. **AB + ĀC + BC = AB + ĀC**（冗余消去）
7. **(A+B)‾ = Ā·B̄；(AB)‾ = Ā+B̄**（摩根）
8. **A + BC = (A+B)(A+C)**（第二分配律）
9. (A‾)‾ = A（还原律）
10. A⊕B = ĀB̄? 即 A⊕B = AB̄ + ĀB；A⊙B = AB + ĀB̄

**编号规则**

- 最小项 mᵢ：原变量=1，反变量=0；n 变量共 2ⁿ 个；任意两个之积为 0、全体之和为 1。
- 最大项 Mᵢ：原变量=0，反变量=1；任意两个之和为 1、全体之积为 0。
- 关系：F = Σm(i) ⟺ F = ∏M(其余编号)；mᵢ 与 Mᵢ 互为反函数。

**卡诺图要诀**

- 格雷码排列 00,01,11,10；循环相邻（两端、四角）。
- 圈矩形、2ⁿ 个格、尽量大尽量少、每圈有新 1。
- 2ᵏ 格消 k 变量；0 少圈 0 再摩根取反；无关项有利才圈。
