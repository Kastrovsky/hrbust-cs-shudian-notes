## 第1章 模拟电子元件与分立电子元件

- **考法 1｜二极管电路计算**：给电源 + 电阻 + 二极管，求电流/电压。套路——先比电源与死区电压判**导通/截止**，导通用**恒压降模型 0.7 V（硅）**，截止则 $I\approx0$。
- **考法 2｜三极管工作区判别**：给 $U_{CC},R_C,I_B,\beta$ 求 $I_C,U_{CE}$。套路——先按放大区算 $I_C=\beta I_B$，再验算 $U_{CE}$：$>0.7$ V 放大、$\le0.7$ V 饱和、$U_{BE}<0.5$ V 截止。
- **考法 3｜电位判型（选择题）**：给三脚电位判管型/电极。套路——找 ≈0.7 V（硅）/0.3 V（锗）压差定 b、e；$U_C$ 最高为 **NPN**、最低为 **PNP**。
- **考法 4｜稳压管电路**：求限流电阻电流、判断是否安全。套路——$U_I>U_Z$ 时反向击穿稳压，端电压钳位 $U_Z$，$I=(U_I-U_Z)/R$ 与 $I_{ZM}$ 比较。
- **考法 5｜场效应管工作状态判断**：给 $U_{GS}$、$U_{DS}$ 判四个区。套路——先比 $U_{GS}$ 与 $U_{GS(th)}$（或 $U_P$）判有无沟道，再比 $U_{DS}$ 与 $U_{GS}-U_{GS(th)}$ 判可变电阻区/饱和区。**增强型 MOS $U_{GS}=0$ 时截止**。
- **考法 6｜共射放大电路计算（大题高频）**：求 Q 点、$A_u$、$r_i$、$r_o$。套路——静态估算法三步（$I_B\to I_C\to U_{CE}$）；动态先画交流通路再套公式：$r_{be}=300+(1+\beta)\frac{26}{I_E(\mathrm{mA})}$、$A_u=-\frac{\beta R_L'}{r_{be}}$、$r_i\approx r_{be}$、$r_o\approx R_C$。**$A_u$ 的负号不能漏**。
- **考法 7｜分立元件门电路识别**：给二极管/三极管电路判是哪种门。套路——**二极管阴极共接输出→与门**（电阻接 $+U$）；**阳极共接输出→或门**（电阻接 $-U$）；三极管共射开关→非门。功能口诀：与门"有 0 出 0、全 1 出 1"，或门"有 1 出 1、全 0 出 0"。
- **考法 8｜概念辨析**：模拟/数字信号、多子/少子、电击穿/热击穿、开关状态、电压控制 vs 电流控制。套路——记结论式表达（连续 vs 离散；多子看掺杂、少子看温度；BJT 电流控制、FET 电压控制）。

## 第2章 数字电路基础

- **考法 1｜数制互转（含小数）**：十进制↔二/八/十六。套路——整数**除基取余逆序**、小数**乘基取整顺序**；小数可能不终止，按精度截断（0.1% 取至第 10 位）。
- **考法 2｜分组速算**：一长串二进制写八/十六进制。套路——二↔八 **3 位一组**、二↔十六 **4 位一组**，不足补零（整数补高位、小数补低位）。
- **考法 3｜码制**：BCD↔十进制、判断有权/无权/自补。套路——8421 每位十进制对 4 位二进制；余3 = 8421 + 3；格雷码无权。
- **考法 4｜机器数**：给真值求原/反/补码，或给补码求真值+范围。套路——负数补码 = 数值取反 + 1（符号位不变）；补码转原码再求一次补。
- **考法 5｜补码加减法**：如 8 位补码算 $13-27$。套路——减法转"加 $[-Y]_补$"，符号位参与、**进位舍弃**、负结果再求补还原真值。
- **考法 6｜概念简答**：为什么用补码？组合 vs 时序？套路——补码"零唯一 + 减法转加法"。

## 第3章 逻辑代数基础

- **考法 1｜口诀填空**：与/或/与非/或非/异或/同或的口诀。套路——"全 1 出 1""全 0 出 1""相异为 1"要能秒答。
- **考法 2｜摩根定律应用**：多层非号展开。套路——去非号→去括号，逐层应用 $\overline{A+B}=\bar A\bar B$、$\overline{AB}=\bar A+\bar B$。
- **考法 3｜对偶 vs 反演辨析**：给函数式分别写反函数与对偶式。套路——**反演变量取反、对偶变量不取反**，运算符与/或互换。
- **考法 4｜标准形式转换**：与或式 ↔ 最小项之和/最大项之积。套路——补项配平得 $\sum m$；由"补编号"得 $\prod M$（m 原变量=1、M 原变量=0）。
- **考法 5｜卡诺图化简（大题高频）**：4 变量函数化简。套路——格雷码填图 → 圈尽量大尽量少且每圈有新 1 → 写最简与或式；升级要求画逻辑图或"仅用与非门实现"（两次取反）。
- **考法 6｜无关项化简**：8421 码类（10~15 不出现）。套路——$\times$ 用足即可，常能化到极简（如 $F=D$）；不可圈"只含 × 的圈"。

## 第4章 组合逻辑电路

- **考法 1｜给图分析**：写式 → 化简 → 真值表 → 归纳功能。套路——逐级推导（设中间变量），结论落到**一句话电路功能**。
- **考法 2｜器件实现（译码器）**：用 74LS138 实现最小项之和。套路——$\bar Y_i$ 低有效，取对应输出接**与非门**；使能端 $S_1=1$、$\bar S_2=\bar S_3=0$ 必须正确。
- **考法 3｜器件实现（数据选择器）**：用 74LS153/151 实现函数。套路——地址端选变量、数据端填 **0/1/单变量及其反**；$F=\sum m_iD_i$。
- **考法 4｜器件扩展**：138 扩成 4-16 线、283 扩成多位、比较器扩位。套路——最高位地址做片选；级联"片内并行、片间串行"。
- **考法 5｜加法器/减法器**：74LS283 级联、加补码实现减法。套路——取反 + $CI=1$；$CO$ 作符号，负结果再求补。
- **考法 6｜竞争冒险**：判断类型 + 消除。套路——代数法 $A+\bar A$（0型）/$A\bar A$（1型）；**加冗余项**消除最常考。

## 第5章 触发器

- **考法 1｜波形图题（最高频）**：给 CP 与输入波形，画 $Q$ 波形。套路——先标所有"有效时刻"（电平型取 $CP=1$ 区段，边沿型取 CP 跳变沿），每个时刻取**前一瞬间**的输入值查功能表，其余时间画平线；遇禁用/不定态画阴影标 ×。
- **考法 2｜基本 RS 触发器分析**：给 $S_D$、$R_D$ 波形求 $Q$。套路——**与非门型低电平有效**：$S_D=0$ 置 1、$R_D=0$ 置 0、11 保持、00 之后**不定**。约束 $S_D+R_D=1$（或非门型才是 $S_DR_D=0$）。
- **考法 3｜同步 RS 与空翻**：问某 CP 周期内输出翻了几次。套路——$CP=1$ 期间输入每变一次就翻一次 → **空翻**；消除靠主从/边沿结构。同步 D 用反相器强制互补，$Q^{n+1}=D$，但仍有空翻。
- **考法 4｜主从 JK 波形与一次变化**：给输入波形画 $Q$。套路——**下降沿触发**、判据取沿前一瞬间；若 $CP=1$ 期间输入变化，只有"$Q=0$ 时 $J:0\to1$""$Q=1$ 时 $K:0\to1$"两种情况会**错翻一次且不恢复**。
- **考法 5｜特性方程与驱动表**：由特性表求方程、由状态变化反求输入。套路——画次态卡诺图化简；驱动表口诀"**0→1 给 $J$，1→0 给 $K$，不变给 0、另一端给 ×**"。
- **考法 6｜触发器功能转换（大题）**：用 JK 实现 D/T/T′，或用 D 实现 JK。套路——**写两个特性方程 → 恒等变形 → 对比系数**。结论：JK→D 用 $J=D,K=\bar D$（须加反相器）；JK→T 用 $J=K=T$；D→JK 用 $D=J\bar Q^n+\bar KQ^n$；D→T′ 用 $D=\bar Q^n$。**转换方向不能反。**
- **考法 7｜集成芯片读表**：74LS74/74HC74/74HC273（**上升沿 D**）、74LS73/74LS112（**下降沿 JK**）。套路——**三步判**：异步端 $R_D$、$S_D$、$CLR$、$MR$（低有效、优先级最高）→ 有无跳变沿 → 数据端。74LS73 只有清零、74LS112 有清零+预置。
- **考法 8｜触发器应用设计**：消抖电路、抢答器。套路——消抖用"**只认第一次**"的 RS 记忆吃掉抖动；抢答器用"**按键 + RS 触发器（记忆）+ 交叉互锁（封锁他人）+ 公共复位 + LED**"，可靠性来自硬连线互锁。

## 第6章 时序逻辑电路

- **考法 1｜分析给定时序电路**：写驱动方程、状态方程、输出方程，列状态表、画状态图、说功能。套路——**六步法**；异步电路必须先写时钟方程；含无效状态以查自启动。
- **考法 2｜设计同步时序电路**：序列检测器等。套路——**八步法**：抽象→状态图/表→化简→编码→选触发器→求激励/输出→画图→查自启动。
- **考法 3｜用 74161 构成任意进制计数器**：清零法/预置数法。套路——**同步**预置译码 **M−1**（异步清零译码 M）；分清同步/异步差 1。
- **考法 4｜74LS194 功能分析**：模式表、移位方向、环形/扭环形。套路——$S_1S_0$ = 11 置数/01 右移/10 左移/00 保持；环形模 $N$、扭环形模 $2N$。
- **考法 5｜序列检测器设计**：设计 Mealy/Moore 型检测电路。套路——抽象状态（收到几个目标位），编码后对次态卡诺图化简；注意 Moore 与 Mealy 状态数差异。

## 第7章 集成运算放大器和脉冲波形的产生与变换

- **考法 1｜判断运放工作状态**：有负反馈→线性区→**虚短+虚断**；开环或正反馈→非线性区→**只剩虚断**，输出 $\pm U_{o(sat)}$。
- **考法 2｜反馈类型四判**：极性法定正负、**输出短路法**定电压/电流、**输入短接法**定串联/并联。套路——接基极为并联、接发射极为串联；三个维度分别作答。
- **考法 3｜比较器画波形**：先标阈值线（$U_R$ 或 $U_H/U_L$），逐段判输入在哪一侧；迟滞型**去程回程用不同阈值**。
- **考法 4｜迟滞比较器门限**：$U_H=\frac{R_1}{R_1+R_2}U_{om}$，$U_L=-U_H$，回差 $=2U_H$；加参考电压只平移、不改回差。
- **考法 5｜555 功能表判断**：算 $\frac13V_{CC}$、$\frac23V_{CC}$ → 比 TH、TL → 查表定输出与放电管；**Rd 优先级最高**，7 脚与 3 脚反相。
- **考法 6｜555 三大电路参数计算**：多谐振荡器 $T\approx0.7(R_A+2R_B)C$、$q=\frac{R_A+R_B}{R_A+2R_B}$；施密特 $V_{T+}=\frac23V_{CC}$、$V_{T-}=\frac13V_{CC}$；单稳态 $t_w\approx1.1RC$。
- **考法 7｜由接法反推电路类型**：看 2、6、7 脚——接电容且 7 在两电阻之间→**振荡器**；2、6 并接输入且 7 悬空→**施密特**；2 接触发、6、7 接电容→**单稳态**。
- **考法 8｜占空比调节设计**：反并联二极管分离充放电路径 → $q=\frac{R_A}{R_A+R_B}$；保持 $R_A+R_B$ 不变即"调占空比不改周期"。

## 冲刺口诀（一页速记）

- **先判断后计算**：二极管/三极管电路先判状态（导通/截止、放大/饱和），再列式。
- **数制"逆序与顺序"**：整数除基取余逆序、小数乘基取整顺序。
- **补码"参与、舍弃、再补"**：符号位参与运算、进位舍弃、负结果再求补。
- **化简"最少"**：与项最少 + 每项变量最少；卡诺图格雷码 + 循环相邻 + 每圈有新 1。
- **分析四步 / 设计四步**：图→式→表→功能；功能→表→式→图。
- **译码低有效用与非**；**选择器 $F=\sum m_iD_i$**；**比较高位优先**。
- **冒险加冗余项**；**时序先写时钟方程、必查自启动**。
- **触发器"三代"**：电平（空翻）→ 脉冲/主从（一次变化）→ 边沿（无缺陷）；判次态只取**触发沿前一瞬间**的输入。
- **五大特性方程**：RS $S+\bar RQ^n$（$RS=0$）、JK $J\bar Q^n+\bar KQ^n$、D $=D$、T $=T\oplus Q^n$、T′ $=\bar Q^n$。
- **JK 口诀**：00 保持、01 置 0、10 置 1、11 翻转；**驱动表** 0→1 给 $J$、1→0 给 $K$。
- **触发沿**：主从 JK 与 73/112 **下降沿**，74/74HC74/273 **上升沿**；异步端低有效、优先级最高。
- **转换三步**：写两方程 → 变形 → 对比系数（JK→D 的 $K$ 必须加反相器）。
- **运放先看反馈**：负反馈才虚短，虚断永远在；开环正反馈只有两级输出。
- **比较器一阈值、施密特两阈值**；回差不是毛病，是抗干扰的本钱。
- **555 记两个数**：$\frac13V_{CC}$ 置位、$\frac23V_{CC}$ 复位，2 脚低置位、6 脚高复位。
- **脉冲三兄弟**：振荡器自激（$0.7$ 系数）、施密特整形（$\frac13V_{CC}$ 回差）、单稳态定时（$1.1RC$）。
