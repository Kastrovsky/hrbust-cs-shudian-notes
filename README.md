# 哈理工计算机数电学习复习资料 · HRBUST Computer Digital Circuits Study Notes

**哈尔滨理工大学 · 数字电路与逻辑（数电）自学与复习资料库**
*Harbin University of Science and Technology · Digital Circuits & Logic — self-study & exam review notes*

> **适用对象**：哈尔滨理工大学 **计算机类专业**《数字电路与逻辑》（课程号 U040023XN02，俗称"数电"）的**自学与期末复习**。
> **其他专业仅供参考** —— 电气、自动化、通信等专业虽然同修此课，但学时、考试范围、命题风格与计算机类专业并不相同，请以本专业老师划定的范围为准。

这是一套从零散课件、原卷、练习题**重新整理、逐题推导、逐图重绘**过的个人复习资料，不是课件搬运，也不是官方教辅。它面向"能不能自己在宿舍里把数电学会并考过"这件事，所以每一节都写成能独立读懂的六段结构：

> **是什么 → 原理与特性 → 符号与图形 → 典型例题·应用 → 易错点 → 知识点总结**

## 四、公式与配图

- **公式**：全部 KaTeX 写法。数学模式里**不出现汉字**（下标写 `_{\text{原}}`），因此在 Gitee / GitHub / Typora / VS Code 里都能正常渲染。
- **万一公式显示成 `[Math Processing Error]`**：说明你用的预览器没加载 MathJax，与文件无关。用 `scripts/build_html.js` 可以生成一份**自包含 HTML**（KaTeX 构建期编译、字体内嵌、不联网），双击即可离线阅读、可打印：
  ```bash
  npm i katex markdown-it
  node scripts/build_html.js "计算机专业真题/数字电路与逻辑_期末习题集_含答案与解析.md" \
                             "计算机专业真题/数字电路与逻辑_期末习题集_含答案与解析.html"
  ```
- **配图**：原卷图一律从原卷整页扫描**按墨迹包围盒重裁**，四边留白、不切字、不吞邻题；课件图取自课程课件原图，非手绘。图片宽度统一压到 ≤1000 px，手机上看也不至于一张图占满整屏。

## 七、给"想继续维护它"的人与 Agent

仓库自带一套维护规则与校验脚本，**人和 Agent 都能照着做**：

- 想接手维护 → 读 [`AGENTS.md`](AGENTS.md)（五分钟看懂结构与铁律）
- 想让自己的 AI 助手接管 → 读 [`agent/使用说明.md`](agent/使用说明.md)（含随仓技能的安装方法）

`agent/skills/` 下随仓带了两个技能，装到本地就能用：

| 技能 | 作用 |
|---|---|
| `skill-router` | 开工前先判断该用哪个技能——命中就按它的流程走，没命中才用通用能力 |
| `shudian-maintain` | 本仓库专用：六段骨架、台账登记、配图与公式的硬约束、校验命令、常见任务做法 |

```bash
python scripts/check_links.py       # 全仓相对链接 + 图片引用体检（0 断链才算过）
python scripts/check_secrets.py     # 提交前凭据闸门（0 命中才允许推送）
python agent/skills/skill-router/scripts/quick_validate.py   # 技能包完整性自检
```
