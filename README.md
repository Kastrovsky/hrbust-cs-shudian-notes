## 开场白：懂的都懂

先说个大家都心知肚明的事实：**上课听没听讲，和期末能不能过，其实是两件独立的事。**

讲台上 PPT 翻得飞快，你刚把标题抄完，老师已经讲到第五章；好不容易某一节听懂了，回宿舍翻开笔记本，发现上面只郑重地写着两个字——"触发器"。至于触发器到底什么时候翻转、JK 和 D 有什么区别，笔记上是一片辽阔的空白。

**这份资料就是为这种时刻准备的。**

> **知道大家上课也不会听讲（早八、后排、手机、窗外那棵树，理由你随便挑），那么这份文件非常适合你拿来自习。**
> 它不假设你听过课，也不假设你记得住黑板上的字。每一节都从"这是什么"重新讲起，讲到"这题怎么算"为止——你在宿舍床上、图书馆角落、回家的高铁上，都能自己把它学一遍。

**特此声明：文件是自己整理的，并不代表对所有人都适用。**

它是"我的理解 + 我的错题 + 我的复习路径"的产物，不是标准答案，也不是官方教辅。你完全可能觉得某一段讲得绕、某个例题的解法不如老师讲得好——那很正常，挑着下嘴就行，没人强迫你从头读到尾。

> **适用对象**：哈尔滨理工大学 **计算机类专业**《数字电路与逻辑》（课程号 U040023XN02，俗称"数电"）的**自学与期末复习**。
> **其他专业仅供参考** —— 电气、自动化、通信等专业虽然同修此课，但学时、考试范围、命题风格与计算机类专业并不相同，请以本专业老师划定的范围为准（别拿我的复习范围去赌你的考卷）。

这套资料是从零散课件、原卷、练习题里**重新整理、逐题推导、逐图重绘**出来的，不是课件搬运，也不是官方教辅。每一节都写成能独立读懂的六段结构：

> **是什么 → 原理与特性 → 符号与图形 → 典型例题·应用 → 易错点 → 知识点总结**

说白了就是：**先告诉你这玩意儿是啥，再告诉你怎么算，最后告诉你哪里容易翻车。**

## 四、公式和配图：不会让你对着乱码发呆

- **公式**：全部 KaTeX 写法。数学模式里**不出现汉字**（下标写 `_{\text{原}}`），所以在 Gitee / GitHub / Typora / VS Code 里都能正常渲染，不会突然给你一屏 `[Math Processing Error]`。
- **万一公式还是显示成 `[Math Processing Error]`**：那是你的预览器没加载 MathJax，跟文件本身无关。用 `scripts/build_html.js` 能生成一份**自包含 HTML**（公式构建期就编译好、字体内嵌、完全不联网），双击离线读，也能直接打印——打印出来垫泡面也挺平整：

  ```bash
  npm i katex markdown-it
  node scripts/build_html.js "计算机专业真题/数字电路与逻辑_期末习题集_含答案与解析.md" \
                             "计算机专业真题/数字电路与逻辑_期末习题集_含答案与解析.html"
  ```

- **配图**：原卷图一律从整页扫描里**按墨迹包围盒重裁**，四边留白、不切字、不吞邻题（这条踩过四轮坑，图被切断过好几次才学乖）；课件图直接用课程课件原图，不是手绘示意。宽度统一压到 ≤1000 px，手机上看不至于一张图占满整屏。

## 七、想接手维护？还是想让 AI 接手？
